# L1 llm call (B5)

- Tests first: all failed at import (`ModuleNotFoundError: llm_call`); then green.
- Real openai exceptions built with `httpx2.Request/Response` (installed openai 3.35.1 uses httpx2, not httpx).
- `retries` = extra attempts after the first (retries=2 => 3 attempts). `attempts` on LLMUnavailable is the total made.
- Backoff: full jitter, `rand() * base_delay * 2**attempt` (attempt 0-based); no sleep after the final failure.
- Retryable: asyncio.TimeoutError, APIConnectionError, APITimeoutError, RateLimitError, InternalServerError. Everything else (Auth, BadRequest, NotFound, other 4xx, unknown exceptions) propagates unchanged on first occurrence.
- Alternatives rejected: relying on the SDK's built-in `max_retries` (hidden, not testable, no unified error type).
- Residual risk: RateLimitError for hard quota exhaustion (429 insufficient_quota) is retried needlessly, bounded by `retries`. `Retry-After` header is not honored. Callers (agent_loop) must still be switched to this function by integration.
