# R1 replay (B14)

`server/replay.py::run_replay(websocket, scenario, runs_dir, delay_scale)` streams `demo/cached_runs/{scenario}_run.json` (contract-shaped lists). It needs no model key; main must not validate the model before this branch (integration, I1).

Behaviour: scenario must be `aligned`/`adversarial` (also blocks path traversal) else `events.error`. The file is fully validated (list of known event dicts) before anything is sent, so a bad file yields one generic `error` (path/exception text only logged). `delay_ms` is stripped and slept as `delay_ms/1000*delay_scale` (0 in tests); timestamps are refreshed.

Human in the loop: each `tool_pending` is followed by `gate.await_decision`; forged/off-node messages are ignored by the gate. The recorded `tool_resolved` is replayed with the human's `decision` and `is_replan = (decision == "deny")`.

Decisions on ambiguity:
- If the human's decision differs from the recorded one, the recorded `result`/`agent_response` describe the other outcome, so they are replaced (standard denial text, or an "approved by operator" note; agent_response empty). Later recorded events (e.g. replan reasoning) still stream unchanged; the demo is a script, not a simulation.
- Gate timeout: emit `session_complete(reason="gate_timeout")` and stop, like live mode.
- Terminal events: the first recorded `session_complete`/`error` ends the replay (later events are dropped); `session_complete("finished")` is appended only if none was recorded.
- `WebSocketDisconnect` from the socket propagates to the caller.

Rejected: playing the recorded decision without waiting (defeats the demo); tolerating unknown event types (would break the contract silently).
