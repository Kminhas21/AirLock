# S1 seismograph math (B11)

**Traced:** a 3-point baseline has rank-2 covariance. With the fixed `+1e-4*I`, the null direction has variance 1e-4, so a tiny off-plane offset is divided by 1e-4. Baseline (0,0,0),(1,0,0),(0,1,0), point (0.3,0.3,0.05): distance 5.001 (breach). The same shape scaled x10 gives 50.0, so it is not scale invariant. The epsilon is absolute while the data scale varies.

**Fix:** shrinkage `cov_s = (1-a)cov + a*(tr(cov)/d)*I`, a=0.1 (`shrinkage` param), scale floored at 1e-9, `np.linalg.pinv` (no LinAlgError). The target scales with the data, so distance is scale invariant. Threshold is now `CHI2_99_DF3 = 3.368` (sqrt of chi2 0.99 quantile, df=3); the constructor param still overrides.

**Numbers:** before: 5.001 (scale 1), 50.0 (scale 10). After: 0.354 and 0.354.

**Projector:** unchanged; `_to_dict` already pads to 3 coords.

**Tests:** tests/seismograph/test_drift_detector.py. Red before the change (4 failures: near point, scale invariance, constant/threshold, shrinkage param); green after. 200-seed loops over identical/collinear/coplanar/random baselines check no raise and finite distance.

**Magic numbers:** the default threshold change 2.5 -> 3.368 touches no assertion in `test_pipeline --stub-only` (it reads `detector.threshold` dynamically; the explicit `threshold=2.5` there is its own argument). The stub-only run broke only because of S2 (see S2.md).

**Rejected:** a larger fixed epsilon (still scale-dependent); Ledoit-Wolf (overkill with n=3, and the spec fixes the form). **Residual risk:** with a=0.1 the null-direction variance is 10% of the mean variance, so off-plane moves are weighted by ~3x less than in-plane; a=0.1 is a tunable guess.
