# W2 frontend type health (B13)

- `NodeData` is now a `type` alias (not `interface`) so it satisfies react-flow's `Record<string, unknown>` constraint; no shape change.
- `src/types/react-plotly.d.ts` declares a minimal `react-plotly.js` module (`PlotProps`, `PlotTrace`, `PlotMouseEvent`) instead of adding `@types/react-plotly.js`, so package.json is untouched.
- DriftMonitor: the CJS/ESM `.default` interop is kept, via a typed cast through `unknown` rather than `any`; traces are typed `PlotTrace[]`; click handler takes `PlotMouseEvent`.
- KillChain: node components use `NodeProps<Node<NodeData>>`; `nodeTypes` uses `satisfies NodeTypes`, so the `as any` casts and eslint-disable are gone. The `sentinel-decision` CustomEvent detail is typed.
- `useCallback(onDecision, [onDecision])` was an identity wrapper (rejected by the React compiler lint); removed and `onDecision` is passed directly. Behaviour is identical because the memoised value always equalled the prop.
