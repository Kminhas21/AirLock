# D1 live drift

`server/live_drift.py`: `SessionDrift(embedder=None)` owns one `SeismographAnalyzer` and one
`DriftTracker` per session (no module-level mutable session state, so sessions are isolated).
Sync/CPU-only; the caller wraps calls in `asyncio.to_thread`.

- `observe_reasoning` -> `drift_update` (analyzer output re-built through `events.drift_update`
  so the timestamp is real and keys follow the contract) plus a `warning`/`goal_persistence`
  alert when the tracker fires. One alert per call regardless of how many denied tools match.
  Threshold = `analyzer.drift_detector.threshold`.
- `observe_tool_call` -> calls `tracker.observe_call` AND `analyzer.check_circumvention`
  (both, unconditionally); at most one `critical`/`circumvention_detected` alert. Call at
  proposal time so later-denied attempts still count. Counted once in the tracker only.
- `observe_denial` registers on both components.
- `drift_score` in alerts = `tracker.drift_score` (kept simple, per spec; not blended with
  Mahalanobis distance, which is already conveyed by `drift_update`).
- Embedder: `make_embedder(env)`: `SENTINEL_EMBEDDER` = `stub` (default) | `minilm`. `Embedder`
  loads its model lazily, so construction alone cannot detect a missing cache; `make_embedder`
  probes with one `embed("warmup")` and on ANY exception logs a WARNING and returns
  `StubEmbedder`. Unknown values also warn and use the stub. `get_embedder()` caches one
  per process (thread-safe); `_reset_embedder_cache()` is a test hook.

Residual risk: the tracker (server RESOURCE_MAP) and analyzer (seismograph map) category tables
are separate; an alert fires if either flags. The minilm probe makes the first session creation
pay model-load time; pre-warm via `get_embedder()` at startup. Integration (I1) must call
`observe_tool_call` before awaiting the human decision.
