# W1 frontend socket

- URL: `VITE_SENTINEL_WS_URL` (default `ws://localhost:8080/ws`), optional `VITE_SENTINEL_WS_TOKEN` appended as URL-encoded `?token=` (`&` if a query already exists). Empty strings count as unset. Typed in `src/vite-env.d.ts`.
- Pure modules in `src/lib/` (wsUrl, backoff, routeEvent) with vitest tests; the hook only wires them.
- Backoff: `min(max, base*2^n) * (1 - jitter*rng())`, base 500ms, max 10s, jitter 0.3, rng injectable; reset on `onopen`.
- routeEvent: `session_complete` and legacy `task_complete` => `setIsRunning(false)`; `error` => `setIsRunning(false)` + `onError(message)` (hook logs via console.error). Non-JSON frames, non-object frames and unknown events are logged and ignored (previously `JSON.parse` could throw).
- Lint fix: `onclose` reconnects through `connectRef` instead of self-referencing `connect`. Also skip connecting while CONNECTING (avoids duplicate sockets), and null the ref on unmount.
- App.tsx: unchanged in behaviour. It never sends `model` (no model picker exists; we do not invent one); `tool_decision` already carries `node_id`.
- mockServer.cjs: port via `MOCK_PORT` (default 8000, mock only; real backend is 8080), so use `VITE_SENTINEL_WS_URL=ws://localhost:8000/ws` with the mock. It still emits legacy `task_complete`, which the frontend treats as an alias.
- vitest ^5 added as devDependency, `npm test` = `vitest run`; config in vite.config.ts (node env, `src/**/*.test.ts`).
